# 功能需求

来源：项目启动讨论（2026-11-20）。范围以此为准，扩需求先改本文档。

## R1 登录

### R1.1 浏览器登录（保留自旧项目）

- 用户点击登录 → 弹出浏览器窗口（Electron `BrowserWindow`）打开客服中心游戏日志页
- 用户完成登录并进入日志页后，程序自动捕获会话令牌组与角色资料
- 捕获成功后自动关闭登录窗口，账号出现在账号列表中

### R1.2 手动粘贴 token 登录（2026-11-23 修订：恢复旧项目做法，废弃原「粘贴 cookies」设计，见 ADR-0014）

- 用户在自己的浏览器中登录客服中心后，从 DevTools Network 面板复制 4 个字段粘贴到表单：`x-account-token`、`x-role-token`、`x-role-server-id`（默认 `1`）、binding token（可选）
- 程序直接将 4 字段作为令牌组落库，**不经任何浏览器会话**（见 ADR-0014）
- 填了 binding token 时自动拉取 `binding_list` 补角色资料；未填则允许保存，提示缺少角色资料，后续可经 `auth:refreshProfile` 补齐

## R2 多账号（2026-11-23 修订：删除改为归档）

- 保存多个账号（角色资料 + 令牌组 + 各自的流水库），数据完全隔离；角色资料来自服务器（binding_list），无本地备注名
- 一键切换当前账号；所有展示与操作均针对当前账号
- 账号「删除」为**归档（软删除）**：从主页下拉框隐藏，流水与同步进度保留、仍可导出，可在设置页恢复
- 账号编辑仅限**更新 token**（重新粘贴令牌组覆盖）；添加时 roleId 与已有账号重复 → 确认后合并为刷新 token；与已归档账号重复 → 确认后恢复该账号并刷新 token

## R3 数据拉取

- 两个入口，均**入库时始终拉取全量（`changeType=0`）**，获取/消耗过滤只在展示层（ADR-0005）：
  - **同步数据**（按钮）：增量同步到 T（见术语表「同步进度」）；T 为 NULL 时等价于全量拉取
  - **获取全部历史数据**（按钮）：翻页至上游返回尽头（`hasNext=false`）
- 上游分页**只能从最新往旧翻、无日期参数**：任何拉取途中经过的记录一律 upsert，不丢弃已下载的数据（ADR-0015）
- 增量不重复请求：早停条件「本页全部已知且最新记录 ≤ T」；CSV 导入产生的孤岛在下次「同步数据」时被穿越吸收（ADR-0015）
- 拉取结束时若停点在旧 T 之上（`hasNext=false` 先于到达 T，缺口不可获取）：发**非阻塞通知**告知区间，不弹选择框（ADR-0015）
- 拉取过程中显示**按日期比例**的进度条（分母 = T，全量拉取时用 `maxLookbackDays` 预测值），不需要精确到条

## R4 码表自动更新

- **每次拉取数据时自动**同步 changeReason 码表；设置页另设手动「检查码表更新」按钮（2026-11-23 修订 ADR-0006）
- 同步顺序（逐级回退，任一成功即止）：官方前端 JS 解析 → 沿用本地缓存 → 内置兜底表（ADR-0010：仅官方源）
- 同步失败不阻塞数据拉取；未知码按「未知原因(码)」展示

## R5 导入导出（2026-11-23 修订：11 列 camelCase + isoTime 权威列，ADR-0013）

- 导出：11 列 camelCase 表头——前 6 列人读、后 5 列（isoTime + 原始码）机器权威（见 docs/csv-format.md、ADR-0013）；`time` 按系统时区无偏移，`isoTime` 为 ISO 8601 UTC（`Z` 结尾）；UTF-8 BOM、文件名附 `_uid{roleId}`；解析与生成统一用 papaparse
- 导入：接受本项目导出与旧项目两种文件（按表头区分）；本项目格式只解析 `isoTime` 定时间，老格式（无偏移）由用户选择时区（默认上海）
- 导入的目标账号由用户显式选择（默认当前账号）；文件名 UID 命中已知账号时预选，仍需确认
- 导入前预检：总行数 / 拒绝行 / 与库内 `seqId` 重复数 / 判定的文件格式与所用时区（旧格式）
- 导入解析后按 `seqId` upsert 进目标账号流水库

## R6 数据展示（待后续讨论，先约束数据口径）

- 展示与统计**基于当前账号流水库的全量历史**，而非单次拉取结果
- 汇总口径沿用旧项目：期初、期末、净变化、获取/消耗、按原因、按日
- UI 细节（布局、图表、报告图是否保留）另文档化于 docs/ui.md；页面结构为**主页（数据获取与展示）/ 设置页（lookback、CSV 导入导出、用户管理、码表）**两页（见 ui.md）

## R7 设置（2026-11-23 新增；同日修订为只读展示）

- 最多可获取天数 `maxLookbackDays` 在设置页**只读展示**自动检测值（官方游戏日志页文案解析；未实现前由 TBD 异步存根恒返回 90），用户不可手动修改
- **纯咨询**：不限制拉取深度（事实边界由 `hasNext=false` 现场感知），仅影响进度条分母与「推荐获取全部历史数据」提示
- 自动检测值与上次不同 → 提示「推荐获取全部历史数据」；拒绝则按增量同步继续
