# CSV 导入导出格式规范

列结构 v2（ADR-0013）：固定 10 列——**前 6 列便于人读，后 4 列保留原始数值**。时间列按系统时区转换并带显式偏移（ADR-0012）、文件名附带角色 UID、UTF-8 BOM。

## 导出格式

- 表头（固定 10 列，UTF-8，**带 BOM** `\uFEFF`）：

```csv
时间,资源类型,原因,变动类型,变动数量,变动后存量,资源类型码,原因码,变动类型码,seqId
```

- 行粒度：一笔流水一行；**单文件单币种**（文件名含币种编号）
- 列语义：

| 列 | 来源 | 说明 |
|----|------|------|
| 时间 | `changeTime` | `YYYY-MM-DD HH:MM:SS±HH:MM`，按系统时区转换并附其显式偏移（如 `+08:00`），与系统时区一致（ADR-0012） |
| 资源类型 | 币种名 | 源石 / 嵌晶玉 / 武库配额 |
| 原因 | 码表映射 | 未收录码为 `未知原因(N)`；导入时仅供参考 |
| 变动类型 | `changeTypeName` | 获取 / 消耗 |
| 变动数量 | `signed_delta` | **带符号**：获取 `+100` / 消耗 `-50`（`changeType==2` 取负） |
| 变动后存量 | `after` | |
| 资源类型码 | `currencyType` | 数字原值（1/2/3） |
| 原因码 | `changeReason` | 数字原值（字符串） |
| 变动类型码 | `changeType` | 数字原值（1/2） |
| seqId | `seqId` | 去重键 |

- 排序：时间倒序（最新在前）
- 分隔符 `,`，引号 `"`，QUOTE_MINIMAL（值含 `,` `"` 换行时加引号，内嵌引号翻倍），行尾 `\r\n`
- 文件名：`endfield_{currency_type}_{start}_{end}_uid{roleId}.csv`
  （如 `endfield_1_2026-11-01_2026-11-20_uid12345678.csv`；UID 用于导入时预选账号）

## 导入格式

**接受**（按表头识别格式，无法识别则整体拒绝）：

1. 本项目 v2 导出（10 列表头如上）——完美往返
2. 旧 Python 项目导出（8 列表头 `时间,资源,变动类型,原因码,原因,变动数量,变动后存量,seqId`，无 BOM 亦可）
3. BOM + UTF-8/UTF-8-BOM 编码；其他编码（GBK 等）明确报错提示，不猜测

**解析规则**：

- **格式判定按表头**（v2 十列 / 旧八列）；同一文件内混用两种时间格式（带偏移与纯格式）= 非法文件，整体拒绝
- **v2 格式以码列为准**：资源类型码 / 原因码 / 变动类型码 / seqId 直接入库；「资源类型」「原因」两列仅参考**不导入**（本地以最新码表解释原因码）
- v2 格式变动数量的符号须与变动类型码一致（+↔获取、−↔消耗），冲突的行拒绝
- 旧格式：资源名 → `currency_type`（源石=1 / 嵌晶玉=2 / 武库配额=3），未知资源名该行拒绝；变动类型名 → `change_type`（获取=1 / 消耗=2）；原因码列取数字
- 时间：v2 带偏移按偏移解析；旧格式为纯 `YYYY-MM-DD HH:MM:SS`，按用户选择的时区（**默认 Asia/Shanghai**，旧项目导出口径，与显示时区无关）解析为 unix 秒；解析失败该行拒绝
- seqId 必须为正整数；缺失/非整数的行拒绝

**归属账号（导入对话）**：

- 目标账号**由用户显式选择**（默认当前账号），不做静默自动分配——错误归属会污染目标账号的流水库
- 文件名含 `_uid{roleId}` 且匹配已知账号时，预选中该账号，仍需用户确认；老格式文件走手动选择

**导入前预检**（用户确认后才执行）：总行数 / 拒绝行及原因 / 与库内 `seqId` 重复条数 / 判定出的文件格式、时间格式与所用时区（旧格式时区在此步仍可调整）。

**写入语义**：按 `(account_id, currency_type, seqId)` upsert 进目标账号流水库；完成后报告新增/覆盖条数。多文件、多币种可一次导入（各文件币种独立判定）。

## 设计取舍

- **不加账号列**：保持列语义简洁，多账号归属靠「文件名 UID 预选 + 导入时确认」（ADR-0009）；API 全部字段均已入列（时间/币种/原因/类型/数量/存量/序号 + 各自原始码），无需额外列
- **可读列在前、原始码在后**：人读前几列即可；机器往返以尾部码列为准（ADR-0013）
- **时间列带系统时区偏移**：自描述、可与老格式区分来源；同一数据在不同时区机器上导出的字面值不同、但表示同一时刻，导入按偏移解析后无损。代价是 Excel 可能不识别为日期类型（ISO 字典序即时间序，排序不受影响）
- **导出前不重新拉取**：直接导出流水库中该范围数据（与旧项目行为不同：旧项目导出时会重新请求上游）
- 汇总报告 PNG 等富导出：不在本格式范围，待数据展示需求确定（docs/ui.md）
