# ADR-0010：码表同步仅使用官方源

- 状态：已接受（2026-11-23，用户决策）
- 修订：ADR-0006 的同步链路（移除 GitHub raw / jsDelivr 镜像两级回退）

## 背景

ADR-0006 的回退链为「官方 → GitHub raw → jsDelivr 镜像 → 本地缓存 → 内置兜底」。实际真源只有官方一个；第三方镜像（旧项目仓库、CDN）增加外部依赖与维护成本，收益有限。先只考虑官方，以后需要再改进。

## 决策

同步链精简为三级，任一级成功即止：

1. 官方：解析客服中心前端 JS chunk（提取原因码对象，见 upstream-api.md）
2. 本地缓存（userData `change_reasons.json`，含热重载）
3. 内置兜底表（随包分发）

## 后果

- 减少外部依赖与测试面
- 官方页面结构变更时只能退到本地缓存/内置表；届时再评估是否恢复第三方源（修订本 ADR）
