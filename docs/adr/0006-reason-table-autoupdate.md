# ADR-0006：码表在每次拉取时自动同步

- 状态：已接受（2026-11-20）；同步链路被 ADR-0010 修订（仅官方源，移除 GitHub/jsDelivr）

## 决策

每次数据拉取流程开始时自动触发 changeReason 码表同步，**无任何手动按钮**。同步链逐级回退，任一级成功即止：

1. 官方：解析客服中心前端 JS chunk（提取原因码对象）
2. GitHub raw（旧项目仓库 `change_reasons.json`）
3. jsDelivr 镜像（同文件）
4. 本地缓存（userData `change_reasons.json`，含 mtime 热重载）
5. 内置兜底表（26 条，随包分发）

## 后果

- **同步失败永不阻塞数据拉取**：全链路失败静默沿用第 4/5 级，未知码显示「未知原因(N)」
- 每次拉取多一次轻量网络往返（官方页面 HTML + 若干 chunk）；可接受，不做 TTL 缓存——失败回退已覆盖离线场景。若实测过重再加「24h 内不重试」的门限
- 诊断入口保留：`reasons:status` IPC 查看当前版本/来源（旧项目的「手动更新/粘贴 JSON」功能不保留 UI，文件仍可手改）
- 码表写入沿用旧项目原子写（`.tmp` → 校验 → `replace`）与 `"0": "其他"` 恒补回
