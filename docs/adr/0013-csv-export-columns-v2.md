# ADR-0013：CSV 导出列结构 v2——可读列在前，原始码在后

- 状态：已接受（2026-11-23，用户决策）
- 修订：ADR-0004 / ADR-0009 中「列结构沿用旧项目 8 列」的决策

## 决策

导出固定 10 列，前 6 列便于人读，后 4 列保留原始数值：

```csv
时间,资源类型,原因,变动类型,变动数量,变动后存量,资源类型码,原因码,变动类型码,seqId
```

- 变动数量**带符号**（获取 `+100` / 消耗 `-50`）；变动类型仍为「获取/消耗」文字
- 导入以**码列**（资源类型码 / 原因码 / 变动类型码 / seqId）为准，名称列仅参考不导入
- 导入按表头识别格式：v2 十列 vs 旧项目八列；无法识别则整体拒绝

## 理由与后果

- 人读 CSV 时先看前几列（时间/资源/原因/数量）；原始码在后保证机器往返无损、不依赖码表版本
- API 全部字段均已覆盖，无缺列；账号归属仍靠文件名 UID + 导入确认
- 与旧 8 列格式不再兼容 → 导入侧同时支持两种格式（按表头分支，成本可控）
- v2 行内变动数量符号与变动类型码冲突 → 视为损坏数据，整行拒绝
