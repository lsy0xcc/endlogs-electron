# UI 结构与数据展示

> 页面结构已定案（2026-11-23）；数据口径约束见下，明细展示形态（图表、分页等）待讨论时在此文档展开。

## 页面结构（2026-11-23 定案）

两页：**主页**（数据获取与展示）、**设置页**。导航具体形式（侧边栏 / 顶部 tab）待 UI 细化。

### 主页

- 第一行（操作区）：
  - **账号下拉框**：选择当前账号；最后一项为「添加新用户」→ 弹出添加账号 modal，内选**浏览器登录**或**粘贴 token**（R1）
  - **两个拉取按钮**：「同步数据」「获取全部历史数据」（R3、ADR-0015），拉取中显示按日期比例的进度条
  - **导出 CSV 按钮**：导出当前账号数据（11 列 camelCase 格式、日期范围默认全部，见 csv-format.md）
- 其余为数据展示区（汇总卡片、明细表等，见「已确定的口径约束」与待讨论清单）
- **无任何账号时**：弹出添加账号 modal 引导用户完成第一个账号

### 设置页

- **最多可获取天数**：只读展示自动检测值（R7；解析未实现前由 TBD 存根恒返回 90）
- **CSV 导入**：入口；预检与账号选择规则见 csv-format.md
- **用户管理表格**（CSV 导出与之整合）：
  - 每行一个账号：角色资料（昵称、UID、区服、渠道、等级——均来自服务器，无本地备注名）+ 状态（正常 / 归档）
  - 行内操作：**更新 token**（重新粘贴令牌组覆盖，唯一可编辑项）、**导出 CSV**（选账号 + 日期范围，默认全部）、**归档 / 恢复**
  - 增 = 添加账号 modal（同主页）
- **码表**：手动「检查码表更新」按钮 + 当前码表版本/日期展示（R4；拉取前仍自动同步）

### 归档（软删除）语义

- 归档账号从主页下拉框隐藏；流水与同步进度保留，CSV 导出可用
- 恢复后回到下拉框，数据与同步进度原样接续（seqId upsert 幂等）
- 添加账号时 token 解析出的 roleId 与已存在账号重复：**确认后合并为刷新 token**（不新建实体）
- 与**已归档**账号的 roleId 重复：**确认后恢复该账号并刷新 token**

## 已确定的口径约束

1. 一切展示基于**当前账号的流水库全量**（ADR-0005），日期范围是查询条件不是数据边界
2. 汇总口径沿用旧项目：期初、期末、净变化、获取/消耗、按原因分组、按日分组（含零填充）
3. 三币种并列展示；未知原因码显示「未知原因(N)」
4. 进度条仅用于拉取过程，按日期比例（见 architecture.md）
5. 技术底座：React + shadcn/ui；展示层数据全部经 IPC 查询；时间显示跟随系统时区（ADR-0012）
