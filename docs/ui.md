# UI 结构与数据展示

> 页面结构已定案（2026-11-23）；渲染层现为纯 UI 壳（见「当前实现状态」）；数据口径约束见下，各展示 tab 内容待讨论时在此文档展开。

## 页面结构（2026-11-23 定案）

两页：**主页**（数据获取与展示）、**设置页**。导航为**侧边栏**（品牌 logo + 主页/设置两项 + 底部展示码表版本）；logo 暂为黑色方块占位，待正式图。

### 主页

- 第一行（操作区）：
  - **账号下拉框**：选择当前账号；最后一项为「添加新用户」→ 弹出添加账号 modal，内选**浏览器登录**或**粘贴 token**（R1）
  - **两个拉取按钮**：「同步数据」「获取全部历史数据」（R3、ADR-0015），拉取中显示按日期比例的进度条
  - **导出 CSV 按钮**：弹出导出对话框——账号预选当前账号，币种复选框默认全选（每个币种一个文件），日期范围默认全部；11 列 camelCase 格式见 csv-format.md
- **日期区间选择**：单一数据卡头部的查询条件。单个弹出式区间选择器（shadcn 官方 Range Picker 组合：`Popover` + `Calendar mode="range"` 双月视图，`DateRange` 来自 react-day-picker），一个输入框同时选起止；结束不晚于今天，禁选未来日期
- **数据展示区为单一卡片**：卡片头部为账号信息（昵称 + UID · 区服 · 渠道 · 等级）+ 右侧日期区间选择；分隔线之下为 **tab 页**（汇总 / 按原因 / 按日 / 明细），tab 内容待设计、现为占位
- **无任何账号时**：弹出添加账号 modal 引导用户完成第一个账号

### 设置页

- **最多可获取天数**：只读展示自动检测值（R7；解析未实现前由 TBD 存根恒返回 90）
- **从备份文件恢复**（CSV 导入）：入口；预检与账号选择规则见 csv-format.md。面向用户的语义是「从备份恢复数据」，文案不暴露实现术语
- **用户管理表格**（CSV 导出与之整合）：
  - 每行一个账号：角色资料（昵称、UID、区服、渠道、等级——均来自服务器，无本地备注名）+ 状态（正常 / 归档）
  - 行内操作：**更新 token**（重新粘贴令牌组覆盖，唯一可编辑项）、**导出 CSV**（预选该行账号，币种复选框默认全选、每个币种一个文件，日期范围默认全部）、**归档 / 恢复**
  - 增 = 添加账号 modal（同主页）
- **变动原因对照**（码表）：手动「检查更新」按钮 + 当前码表版本/条数展示（R4；拉取前仍自动同步）。面向用户的语义是「变动编号与文字说明的对照」，文案不暴露实现术语

### 归档（软删除）语义

- 归档账号从主页下拉框隐藏；流水与同步进度保留，CSV 导出可用
- 恢复后回到下拉框，数据与同步进度原样接续（seqId upsert 幂等）
- 添加账号时 token 解析出的 roleId 与已存在账号重复：**确认后合并为刷新 token**（不新建实体）
- 与**已归档**账号的 roleId 重复：**确认后恢复该账号并刷新 token**

## 已确定的口径约束

1. 一切展示基于**当前账号的流水库全量**（ADR-0005），日期范围是查询条件不是数据边界
2. 汇总口径沿用原版 endlogs：期初、期末、净变化、获取/消耗、按原因分组、按日分组（含零填充）
3. 三币种并列展示；未知原因码显示「未知原因(N)」
4. 进度条仅用于拉取过程，按日期比例（见 architecture.md）
5. 技术底座：React + shadcn/ui（原语层 Base UI + Tailwind v4，ADR-0016，遵循 shadcn 官方当前默认）；展示层数据全部经 IPC 查询；日期处理统一用 dayjs（项目内唯一日期库，渲染层经 `lib/time.ts` 薄封装调用，不手写日期格式化）；时间显示跟随系统时区（ADR-0012）
6. **颜色语义**：Lyra 无内置 success/warning 色，主题中自定义 `--success`（绿，获取方向与成功语义）与 `--warning`（琥珀黄）；`--destructive`（红）仅用于错误与危险操作；金额负数（消耗）用默认前景色，不着红

## 当前实现状态（UI-only 阶段，2026-11-24）

- 渲染层保留两页布局与全部交互
- 「同步数据 / 获取全部历史数据」按钮保留但无行为，模拟拉取进度条随 mock 移除（真实进度待数据层，R3）
- 码表数据源改为直接读仓库根 `change_reasons.json`（ADR-0010 内置兜底表，非 mock）；maxLookbackDays 暂为常量 90（R7 TBD 存根）
- 数据层（drizzle schema、IPC、主进程模块）尚未实现
- 渲染进程外链（如指向 endlogs 仓库）经 `setWindowOpenHandler` 走系统浏览器，不新开 Electron 窗口
